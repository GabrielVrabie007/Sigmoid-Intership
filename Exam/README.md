# Multilingual App Review Rating Prediction

Sigmoid internship exam. Predict `rating` from a multilingual mobile app review dataset — and determine whether a prediction is even possible with the given features.

## Key finding

**No model beats the baseline.** After 5-fold CV comparing five candidates (Baseline, Ridge, Random Forest, HistGradBoost, XGBoost) with 40-iteration `RandomizedSearchCV` on the winner:

| Model | CV RMSE | CV R² |
|---|---|---|
| **Baseline (mean)** | **1.150** | **-0.006** |
| Random Forest | 1.167 | -0.036 |
| Ridge | 1.173 | -0.046 |
| HistGradBoost | 1.224 | -0.141 |
| XGBoost | 1.249 | -0.187 |

Held-out test R² ≈ 0.000. An out-of-fold oracle-R² diagnostic shows that **every feature has negative out-of-fold R²** — no column carries usable signal. The dataset appears to be synthetic, with `rating` generated independently of the other fields.

The correct model is `DummyRegressor(strategy='mean')` wrapped in the full preprocessing pipeline. Any gradient-boosted model that scores lower in-sample is memorizing training-fold noise.
